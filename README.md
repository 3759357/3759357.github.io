# Won Seung Hyeok Portfolio

Backend and platform engineering portfolio built with Astro and deployed to GitHub Pages.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

Pushing to `main` triggers the GitHub Pages deployment workflow.
